3. [VocaFlow_Windows_App/]
   -> Thư mục bản chạy sẵn trên máy tính Windows (mở VocaFlow.exe là chạy ngay).

   -> Bản Web chạy độc lập 1-file, mở bằng bất kỳ trình duyệt nào.
